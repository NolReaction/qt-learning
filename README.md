# Qt Learning — первые формы и события

Ранний учебный проект на C++ и Qt Widgets. Автор написал код самостоятельно, без ИИ, чтобы освоить окна, элементы интерфейса, сигналы/слоты и работу с файлами.

**Статус:** историческая работа. Исходный код и [первоначальный readme](readme.txt) сохранены как свидетельство ранней практики desktop-разработки.

## Учебный сценарий

- Главное окно с вводом логина и пароля.
- Проверка введённых данных и открытие второго окна при совпадении.
- Добавление пользователя через диалоги и сохранение записей в текстовый файл.
- Сообщения об ошибках и заготовка переводов интерфейса.

**Стек:** C++17, Qt Widgets, Qt Designer (`.ui`), Qt Linguist и CMake. В репозитории также остался исходный файл проекта qmake.

## Запуск

1. Установить Qt Creator и комплект **Qt 6** с Widgets, LinguistTools и компилятором C++17.
2. Открыть `CMakeLists.txt` и выбрать подходящий Desktop kit. Для этой версии используйте Qt 6: ветка CMake для Qt 5 не включает все исходные файлы текущего приложения.
3. В `mainwindow.cpp` и `passwordchecker.cpp` заменить исходный абсолютный путь `D:/QTProjects/Learning/credentials.txt` на один и тот же путь к своему локальному учебному файлу. Каталог должен существовать и быть доступен для записи.
4. Собрать и запустить через Qt Creator. Использовать только вымышленные логины и пароли.

## Границы примера

Проверка логина здесь — упражнение по формам и файлам: пароли хранятся открытым текстом, а отладочный вывод содержит введённые данные. Это не реализация защиты аккаунтов и не основа для хранения настоящих паролей. Автоматизированных тестов в репозитории нет.

Проект полезен как компактный пример перехода от консольных упражнений к событийной модели GUI и нескольким взаимодействующим классам.
