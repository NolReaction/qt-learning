# Qt Learning

На этом проекте я учился делать оконные приложения на C++ и Qt Widgets. Код писал сам, без ИИ: разбирался с формами, сигналами и слотами, несколькими окнами и чтением файлов. Я сохранил исходники и [старый readme](readme.txt) как часть своей истории обучения.

В качестве упражнения я сделал форму входа. Она проверяет логин и пароль и открывает второе окно при совпадении. Через диалоги можно добавить новую запись и сохранить её в текстовый файл. Ещё я попробовал сообщения об ошибках и подготовил файл перевода интерфейса.

## Что внутри

Я использовал C++17, Qt Widgets, Qt Designer, Qt Linguist и CMake. Старый файл проекта qmake тоже остался в репозитории.

- [main.cpp](main.cpp): запуск приложения и загрузка перевода.
- [mainwindow.cpp](mainwindow.cpp) и [mainwindow.ui](mainwindow.ui): главная форма, вход и добавление записи.
- [passwordchecker.cpp](passwordchecker.cpp): чтение, проверка и сохранение данных.
- [secondwindow.cpp](secondwindow.cpp) и [secondwindow.ui](secondwindow.ui): второе окно.
- [Learning_ru_RU.ts](Learning_ru_RU.ts): исходный каталог перевода.
- [CMakeLists.txt](CMakeLists.txt): настройки сборки.

## Как запустить

1. Установи Qt Creator и комплект Qt 6 с Widgets, LinguistTools и компилятором C++17.
2. Открой `CMakeLists.txt` и выбери Desktop kit. Здесь стоит использовать Qt 6: ветка CMake для Qt 5 не включает все файлы текущего приложения.
3. В `mainwindow.cpp` и `passwordchecker.cpp` замени мой старый путь `D:/QTProjects/Learning/credentials.txt` на один и тот же путь к своему учебному файлу. Каталог должен существовать и быть доступен для записи.
4. Собери и запусти приложение в Qt Creator.

Я делал проверку логина как упражнение по формам и файлам. Пароли здесь хранятся открытым текстом и попадают в отладочный вывод, поэтому используй только вымышленные данные. Для настоящей авторизации этот код не подходит. Автоматизированные тесты я тогда не добавлял.
